# Member 2 upload steps

1. Ask the repository owner to add your GitHub account as a collaborator, or use
   your own fork and a pull request. Commit genuine work using your own account.
2. Ensure Member 3 and Member 1 final uploads have already been merged.
3. Open the shared repository, select Add file > Upload files, and drag all items
   INSIDE Member_2_GitHub_Upload into the upload area, preserving subdirectories.
4. Commit: Add RTO evidence review, video analysis and licensed sample assets
5. Download a fresh combined copy and follow README.md / TEAM_UPLOAD_GUIDE.md.

This package contains fewer than 100 files, each under 25 MiB. Do not upload the
ZIP as a source file. Setup downloads/verifies YOLOX; smaller models and licensed
samples are included. Do not upload the original full Member_2 working folder.
