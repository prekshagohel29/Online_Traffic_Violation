# Smart Traffic Violation & Fine Management System - Frontend

This is the React frontend for the Smart Traffic Violation & Fine Management System.

## Features

- Add Violation: Form to input plate number, violation type, and location
- View Fines: Display all fines with plate numbers
- Analytics: Show violations grouped by location

## Technologies

- React
- React Router for navigation
- Axios for API calls

## Setup

1. Install dependencies:
   ```
   npm install
   ```

2. Start the development server:
   ```
   npm start
   ```

The app will run on http://localhost:3000

## Backend

Ensure the Flask backend is running on http://localhost:5000

## Database

Ensure MySQL is set up with the traffic_system database.
